Bilingual Reader

A paragraph-level translation engine for the web

This extension translates web pages into a bilingual layout. Every paragraph is paired with its translation so you can read the original text and the translated text at the same time.

How it works

The extension scans the page and decides which blocks are real article content. Navigation menus, sidebars, footers and short labels are skipped automatically because they carry little meaning out of context.

  • Paragraph level bilingual layout
  • Lazy translation triggered by scrolling
  • Personal information masking before the request

Reading two languages side by side is a very effective way to learn a new language.

Install the extension from the extensions page, then reload the target page. Click the toolbar icon and choose translate. The keyboard shortcut works as well.
