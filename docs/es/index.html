Bilingual ReaderTraducción bilingüe de páginas web

Traduce el contenido de las páginas párrafo a párrafo y lee el original y la traducción juntos. Conecta la API de tu propio modelo o utiliza un modelo alojado en tu equipo.

Código fuente e instalación Descargar extensión Política de privacidad (chino) Informar de un problema

Puedes descargar e instalar manualmente la última versión desde GitHub Releases. La publicación en Chrome Web Store requiere la revisión de Google.

Aprende inglés mientras lees

Tras traducir la página, selecciona una oración para ver su estructura y sus expresiones clave explicadas en chino sencillo. Selecciona una palabra para consultar su significado en contexto, su transcripción fonética estadounidense y cómo se forma. Escucha las palabras y oraciones con una voz local en inglés y guárdalas en este dispositivo para repasarlas.

Prueba el ejemplo de aprendizaje

Primeros pasos

  1. Descarga el paquete de la extensión desde GitHub Releases y descomprímelo. Abre la página de extensiones de Chrome, activa el Modo de desarrollador y carga la carpeta descomprimida que contiene manifest.json.
  2. Abre los ajustes de la extensión. En Motores de traducción (翻译引擎), añade un proveedor e introduce la URL de la API, el modelo y tu clave. Prueba la conexión y guarda el motor.
  3. Abre una página normal y pulsa Traducir esta página (翻译此页), o utiliza Alt+T. Alterna entre vista bilingüe, solo traducción o solo original, y restaura la página cuando quieras.

Pruébalo primero

Sin clave de API: Ajustes → Motores de traducción (翻译引擎) → añade el modo de demostración (演示模式（本地示例，无需 Key）) → guarda. Después abre la página de demostración en inglés e inicia la traducción. Este modo utiliza un diccionario local para mostrar el diseño y los controles; no representa la calidad de una traducción automática real.

Cómo se tratan tus datos

El desarrollador no opera un servidor que reciba el texto de las páginas ni tus claves. La traducción real envía el texto procesado, las instrucciones y los datos de autenticación directamente al servicio de modelos que configures. Las reglas de enmascaramiento no garantizan identificar todos los datos sensibles. Consulta la política de privacidad completa (chino).
