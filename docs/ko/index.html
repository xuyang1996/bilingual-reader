Bilingual Reader웹페이지 원문·번역문 대조 읽기

웹페이지 본문을 문단별로 번역해 원문과 번역문을 한 화면에서 읽으세요. 직접 설정한 모델 API와 로컬에서 실행하는 모델을 지원합니다.

소스 코드와 설치 안내 확장 프로그램 다운로드 개인정보 처리방침(중국어) 문제 신고

Chrome 웹 스토어 버전은 심사를 위해 제출되었으며, 승인 후 자동 게시되도록 설정되어 있습니다. 현재는 GitHub Releases에서 내려받아 직접 설치할 수 있습니다.

시작하기

  1. GitHub Releases에서 확장 프로그램 패키지를 내려받아 압축을 풉니다. Chrome 확장 프로그램 관리 페이지에서 개발자 모드를 켜고 manifest.json이 있는 압축 해제된 폴더를 로드합니다.
  2. 확장 프로그램 설정의 번역 엔진(翻译引擎)에서 제공업체를 추가합니다. API URL, 모델, API 키를 입력하고 연결을 테스트한 다음 엔진을 저장합니다.
  3. 일반 웹페이지에서 이 페이지 번역(翻译此页)을 누르거나 Alt+T를 누릅니다. 대조 보기, 번역문만, 원문만 표시하는 모드를 전환하고 언제든 페이지를 복원할 수 있습니다.

먼저 체험하기

API 키 없이 체험하려면 설정 → 번역 엔진(翻译引擎) → 데모 모드(演示模式（本地示例，无需 Key）) 추가 → 저장 순서로 진행하세요. 이후 영문 데모 페이지를 열고 번역을 시작합니다. 데모 모드는 로컬 사전으로 레이아웃과 조작을 체험하는 기능이며, 실제 기계 번역 품질을 보여주는 것은 아닙니다.

데이터 처리 방식

개발자는 본문이나 API 키를 수신하는 서버를 운영하지 않습니다. 실제 번역에서는 처리한 본문, 프롬프트, 인증 정보를 사용자가 설정한 모델 서비스로 직접 전송합니다. 마스킹 규칙이 모든 민감 정보를 식별하는 것은 아닙니다. 자세한 내용은 전체 개인정보 처리방침(중국어)을 참조하세요.

영감과 감사

이 프로젝트는 Immersive Translate(沉浸式翻译)에서 영감을 받았습니다. 번역 스타일에는 공개 저장소 immersive-translate/prompts의 시나리오 프롬프트를 이 프로젝트에 맞게 조정해 사용했습니다. Immersive Translate 팀과 프롬프트 기여자들에게 감사드립니다.
