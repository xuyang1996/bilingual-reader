Chrome 拡張機能 · v1.4.0 · MIT オープンソース

Bilingual ReaderWeb ページを対訳で読む

Web ページの本文を段落ごとに翻訳し、原文と訳文を同じ画面で読めます。ご自身のモデル API や、ローカルで動作するモデルを利用できます。

ソースコードと導入手順 拡張機能をダウンロード プライバシーポリシー（中国語） 問題を報告

Chrome ウェブストア版は審査に提出済みで、承認後に自動公開される設定です。現在は GitHub Releases からダウンロードして手動でインストールできます。

使い始めるには

  1. GitHub Releases から拡張機能のパッケージをダウンロードして展開します。Chrome の拡張機能管理ページでデベロッパー モードを有効にし、manifest.json を含む展開済みフォルダーを読み込みます。
  2. 拡張機能の設定を開き、翻訳エンジン（翻译引擎）でプロバイダーを追加します。API URL、モデル、API キーを入力し、接続をテストしてエンジンを保存します。
  3. 通常の Web ページで「このページを翻訳（翻译此页）」を選ぶか、Alt+T を押します。対訳、訳文のみ、原文のみを切り替え、いつでもページを復元できます。

まずは試してみる

API キーなしで試すには、設定 → 翻訳エンジン（翻译引擎）→ デモモード（演示模式（本地示例，无需 Key））を追加 → 保存の順に進みます。その後、英語のデモページを開いて翻訳を開始してください。デモモードはローカルの辞書でレイアウトと操作を体験するためのもので、実際の機械翻訳の品質を示すものではありません。

データの取り扱い

開発者は本文や API キーを受信するサーバーを運営していません。実際の翻訳では、処理した本文、プロンプト、認証情報を、設定したモデルサービスへ直接送信します。マスキングのルールは、すべての機密情報を識別できるとは限りません。詳しくはプライバシーポリシー全文（中国語）をご覧ください。

着想と謝辞

本プロジェクトの着想は Immersive Translate（沉浸式翻译） から得ています。翻訳スタイルには、公開リポジトリ immersive-translate/prompts のシナリオプロンプトを、本プロジェクトに合わせて調整して使用しています。Immersive Translate チームとプロンプトの貢献者に感謝します。
