Bilingual Reader 隐私政策

最近更新：2026 年 11 月 4 日  ·  适用版本：1.4.0

本政策说明 Bilingual Reader — 双语对照翻译（下称「本扩展」）在你使用过程中会处理哪些数据、 数据会流向哪里，以及我们（扩展作者）是否会收集它们。

一句话总结 扩展作者不接收网页正文、API Key 或使用统计，不运营接收这些数据的服务器，也没有广告或遥测。 扩展会在本机保存配置，并在翻译时把待翻译文本、提示词与鉴权信息直接发送到你配置的模型接口。 演示模式不联网；使用本地模型时，请确认接口及模型服务都部署在本机。

1. 我们收集哪些数据

数据类型作者是否接收扩展如何处理
个人身份信息（姓名、邮箱、电话等）不接收不建立个人资料。待翻译正文可能含个人信息；可选的规则脱敏会尝试替换其中部分类型，但不能保证识别全部敏感内容。
浏览历史不收集扩展不上报浏览记录、访问过的网址或使用统计。
网页内容（正文文本）不接收翻译启动后，识别出的正文会直接发送到你配置的 API 服务商；启用自动翻译时，可在页面打开后自动发送。开启增量翻译时也会处理新增正文（见第 3 节）。
正文中的健康、财务、个人通讯或位置信息不接收如果你翻译的网页包含这些信息，扩展会按同一翻译流程处理，并可能发送到你配置的模型接口。扩展不单独索取这些信息，不请求设备定位权限，也不从其他应用读取通讯或医疗记录。
用户输入的 API Key不接收保存在本机 chrome.storage.local，请求时作为鉴权信息发送到你配置的模型接口。
诊断信息 / 崩溃日志不收集扩展不包含任何遥测或崩溃上报代码。

2. 本地存储了什么

以下数据保存在你浏览器的本地扩展存储中。翻译请求会按第 3 节使用其中的配置。 你可以通过「隐私与缓存 → 清空缓存」删除译文缓存，通过「数据与关于 → 恢复默认设置」删除自定义配置与密钥， 或卸载扩展删除其本地存储。导出的 JSON 配置备份包含密钥，请自行妥善保管。

  • 引擎配置：你填写的接口地址、模型名、API Key、鉴权方式、批量条数、超时等。
  • 翻译偏好：目标语言、翻译风格场景、术语库、站点规则、译文样式、阈值等设置。
  • 翻译缓存：已翻译过的段落及其译文，键为「原文 + 语向 + 引擎」的哈希值，默认保留 30 天。 实际保存的是译文、时间戳及原文哈希。译文可能包含个人信息（例如未启用脱敏或规则未识别的信息）。 超过 30 天的条目在再次读取时失效；可随时关闭缓存或手动清空。
  • 会话级记忆：某个引擎上次成功的接口地址与鉴权方式（存于 chrome.storage.session， 浏览器关闭即清除），用于避免每次请求都重复试探地址。
  • 学习收藏：仅保存你主动收藏的单词、句子、对应的解析和单词所在的原句（如有）。可在「学习收藏」中取消收藏。

3. 什么数据会离开你的设备，以及去哪里

真实翻译通过你配置的大模型 API 完成。点击翻译、使用快捷键或右键菜单启动，或启用自动翻译时：

  1. 扩展识别出页面中的正文段落；
  2. 可选的 PII 脱敏会把邮箱、电话、信用卡号、身份证号、IP 地址、网址等替换成占位符 （默认开启，可在设置页关闭或按类型勾选）；
  3. 这些文本连同目标语言、场景提示词、术语库等翻译所需信息，被发送到你自己在设置页填写的那个 API 地址，API Key 按所选鉴权方式随请求发送；
  4. 返回的译文在本地还原占位符并渲染到页面上。

点击「学这句」会把选中的一句英文原文和解析提示词发送到当前模型接口。点击「查单词」会发送单词，并在可用时附上它所在的一句原文。 请求沿用脱敏和鉴权设置，不附带其他段落或网页地址。发音使用设备上的本地英语语音。

因此，你阅读的网页正文会到达你所选择的那家大模型服务商（例如 DeepSeek、OpenAI、 Google，或你自己部署的 Ollama / vLLM / LM Studio）。这些服务的隐私条款由它们各自负责，请以你实际使用的 服务商公布的政策为准。我们不参与这条链路，也不是任何一方的中介。

“测试连接”会向所填接口发送示例文本及所选翻译提示词。请仅向你信任的接口填写密钥，远程服务应使用 HTTPS。 敏感信息脱敏依赖正则规则，不能保证识别全部信息；不要翻译你无权向所选服务披露的内容。 你可以还原页面以停止后续调度，或关闭自动翻译；已经发出的请求及第三方保存的数据受该服务商的政策约束。

如果你不希望任何内容离开本机
请在设置页「翻译引擎」里选择本地部署的 Ollama / vLLM / LM Studio 预设， 并把「鉴权方式」设为「无」。这样请求只发往 localhost，正文不会离开你的电脑。

4. 扩展申请了哪些权限，为什么

权限用途
storage把设置、API Key 与翻译缓存保存在本机。
contextMenus提供右键菜单里的「翻译本页」「还原本页」「仅显示译文」「仅显示原文」。
主机权限 <all_urls> 在任意网页注入内容脚本以识别正文并渲染译文。没有它，扩展无法在任何网站上工作。

扩展不申请 tabs、browsingData、cookies、history、 webRequest、downloads 等敏感权限，也不读取除当前活动标签页以外的标签页信息。

5. 数据共享与出售

我们不出售、共享、转让或出租你的任何数据。扩展没有广告、没有数据分析 SDK、 没有第三方脚本、也没有远程加载的代码。所有代码都打包在扩展包内，运行时不会从外部下载并执行任何脚本。

向用户选定模型接口传输正文和鉴权信息，仅用于提供翻译功能；不用于广告、出售、信用评估或与翻译无关的用途。 本扩展对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括有限使用要求。

6. 演示模式

设置页的引擎列表里有一个「演示模式」。它使用扩展内置的小词表在本地 拼出示例译文，用于让新用户在配置 API 之前先体验界面与流程。它不发起任何网络请求， 也不需要 API Key，其输出在界面上有明确标记。演示模式不是机器翻译， 真实翻译请配置你自己的大模型 API。

7. 儿童隐私

本扩展不专门面向儿童，不建立儿童资料。正文仍可能包含儿童相关信息，向模型服务发送内容前请遵守该服务商的年龄要求与适用规则。

8. 变更

本政策如有变更，会随扩展的新版本一同更新，并在此页标注新的更新日期。

9. 联系我们

如果你对隐私政策有任何疑问，可以在 GitHub Issues 提交问题。请勿在公开 issue 中提交 API Key、私密网页正文或其他敏感信息。

本政策页面与项目网站由 GitHub Pages 托管。访问网站时，GitHub 可能按其 隐私声明处理访问日志；网站本身不加入统计脚本。
