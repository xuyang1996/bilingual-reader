# v1.4.4 网页翻译浮签

普通网页默认在右侧显示「译」浮签，点击即可翻译，翻译后点击「原」可还原。暂停时主按钮为「续」，点击继续翻译。无需每次打开浏览器工具栏面板。

## 操作

- **大小与透明度**：浮签由 48 像素缩为 32 像素，默认 50% 不透明度，鼠标悬停时恢复不透明。键盘聚焦和拖动期间也保持清晰，展开菜单始终不透明。
- **固定右侧、上下拖动**：浮签固定距右边缘 8 像素，只能上下移动。高度以视口比例存入本机，在新页面、刷新和浏览器重启后沿用。缩小窗口时保持在可见范围内。旧版保存的横坐标不再影响位置，原有高度继续沿用；水平拖动也不会误触翻译。
- **悬停菜单**：鼠标悬停或键盘聚焦浮签，展开暂停/继续、重新翻译、还原、设置和关闭入口。有失败段落时还会显示补翻入口。
- **暂停/继续与重译**：复用已有翻译控制器；继续从暂停位置的上一段补接，重译从页首重新请求，不读旧缓存。
- **关闭与恢复**：关闭会隐藏所有普通网页中的浮签，不会停止正在进行的翻译。可从扩展面板的「显示网页浮签」，或设置 →「译文样式」→「显示网页浮签」重新开启；开关立即生效，不必刷新已打开的网页。
- **首次配置**：没有配置可用引擎时，显示配置提示并打开设置页，不发送翻译请求。

浮签出现在扩展能够运行的普通网页中。Chrome 内部页面和 Chrome 应用商店等限制扩展运行的页面仍需遵循浏览器限制。iframe 内不重复显示浮签。

## 实现

`src/content/floating.js` 提供独立的 Shadow DOM 控件，顶层页面仅创建一次。宿主使用 `translate="no"` 和 `notranslate`，不参与正文分段。宿主挂在页面根节点，页面正文的还原、懒加载和常规 SPA 更新不会移除它。

显示开关 `imtl.floating.enabled` 和相对高度 `imtl.floating.position` 分别存储于 `chrome.storage.local`，通过 `storage.onChanged` 在页面、面板和设置间同步。位置结构保留兼容的 `{x: 1, y: 相对高度}`，实际横向布局始终以右边缘为准。拖动只写高度，关闭只写开关，避免覆盖引擎配置或互相覆盖偏好。浮签偏好独立于模型配置的 JSON 导入导出，不向服务端上传。

浮签调用内容脚本现有 `start/pause/resume/retranslate/retry/stop` 路由，进度由同一个 `reportState` 更新。打开设置通过后台 `IMT_OPEN_OPTIONS` 消息执行，不增加扩展权限。

## 验证

从项目父目录启动端口 8766 的静态服务器，再在项目目录串行运行：

```bash
python3 test/verify_floating.py --ext .
python3 test/verify_reliability.py --ext .
python3 test/verify_popup.py --ext . \
  --url http://127.0.0.1:8766/bilingual-reader/demo/demo.html
python3 test/verify_options.py --ext .
```

浮签测试使用隔离 Chrome、真实鼠标事件和本地模拟 API，覆盖点击翻译、悬停菜单、暂停/继续、重译、拖动防误触、位置持久化、跨页面同步、iframe 去重、小视口布局、关闭及重新开启、设置入口与未配置状态。不访问用户的浏览器配置或真实 API Key。
