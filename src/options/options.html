正文识别

阈值决定哪些段落会被当作正文翻译。数值越大，越少的内容被翻译（噪音更少）。

打开后连导航 / 侧栏 / 页脚一起翻；关闭则只翻正文。

译文样式

译文的外观与摆放方式。

在普通网页右侧显示翻译浮签，可拖动摆放，位置会在网页间同步。悬停可暂停、重译、打开设置或关闭浮签；关闭后也可从扩展面板重新开启。此开关立即保存。

站点规则

用 JSON 数组定义按站点生效的规则。规则按匹配强度排序，后匹配到的规则覆盖先前的。字段与 generalRule 相同。

术语库

每行一条：英文原文 中文译法。术语会写进提示词，模型会照着翻。

隐私：PII 脱敏

翻译前把敏感信息替换为占位符，送回后本地还原，原始内容不会离开本机。

缓存

翻译结果缓存在本机，重复访问同一页面时直接命中，不消耗额度。

配置数据

配置只存在本机。可以导出成 JSON 备份，或导入别人的配置。

提示词场景改编自开源项目 immersive-translate/prompts， 翻译风格与术语处理方式可自由自定义。
