What do I need to get started?

You need a working HTTPS model API and a model ID. If the service requires authentication, you also need an API key. Your provider sets any API usage charges.

Where do my text and API key go?

When you translate, the app sends the source text, style instructions and any required credentials directly to your configured model service. On Android, the app stores saved API keys encrypted on your device. Read the privacy policy.

What if the connection test fails?

Check the API type and HTTPS endpoint first, then confirm the model ID, key permissions and provider quota. Use the final API endpoint supplied by your provider.

Can I translate webpages or upload files?

The current Android app translates text you type or paste. Copy the text you need from the webpage or document and paste it into the app.
